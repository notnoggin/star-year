# Star Year

A daily journal that turns your memories into stars.

Inspired by the beautiful **One Year** app, but with a starry constellation identity instead of flowers. Every day you write becomes a hand-drawn star in your year.

## Features

- **Star Garden**: Visual year overview with stars on days you journaled
- **Improved Home Screen**: Monthly sections, progress stats, cleaner navigation
- **Multiple Themes**: Night (original purple), Day, Cosmic Blue, Warm Amber
- **Doodle / Sketchy Aesthetic**: Caveat font, hand-drawn feel
- **Core Flows**: Write memories, view entries, settings, subscription plans
- **Always-On Display**: Landscape doodle star pattern
- **Dynamic Island**: Inspired by [islandcn](https://github.com/opencoredev/islandcn) — shows confirmation when you plant a star

## Improvements over the original

- Better organized year view with month labels
- Prominent progress statistics
- Clearer theme switching
- Smoother transitions
- Ready for voice notes, photos, and custom doodles (premium)

## Getting Started

```bash
npm install
npm run dev
```

Then open the app and start planting stars.

## Tech

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Notes

This is a high-fidelity prototype focused on the core experience and visual language of One Year, adapted with stars. Full photo/voice/doodle capture can be extended.

Built with care for the quiet, consistent practice of noticing your days.
